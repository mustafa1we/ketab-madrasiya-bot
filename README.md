# بوت كتب مدرسية — مكتبة أم القرى

هذا مشروع جاهز لبوت Telegram يرد تلقائيًا باستخدام الذكاء الاصطناعي.

## يحتاج مفتاحين
1. TELEGRAM_BOT_TOKEN من BotFather.
2. OPENAI_API_KEY من حساب OpenAI API.

لا ترسل أي مفتاح داخل المحادثة.

## التشغيل على الكمبيوتر
```bash
pip install -r requirements.txt
```

ثم عرّف متغيرات البيئة من ملف `.env` أو من إعدادات الاستضافة، وبعدها:
```bash
python bot.py
```

## مهم
البوت يستخدم Long Polling، لذلك يجب تشغيل `bot.py` باستمرار على استضافة/سيرفر حتى يبقى يرد والكمبيوتر أو الهاتف مغلق.
